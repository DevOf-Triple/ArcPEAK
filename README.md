# ArcPEAK

Мой небольшой проект, на котором я делаю сайт, для (не)существующей организации!

Чтобы включить базу данных:

1. найдите файл config/db.example.php ;
2. переименуйте в db.php;
3. заполните его своими значениями;
4. (если есть или если необходимо) - импортируйте .sql базу данных в свой PhpMyAdmin.
