# ArcPEAK

Мой небольшой проект, на котором я делаю сайт, для (не)существующей организации!

Чтобы запустить сайт (OSPanel):

1. запустите OSPanel от имени администратора
2. включите модули:
  a) HTTP - Apache;
  b) MySQL - 8.4;
  c) PHP - 8.2.
3. используйте любую онлайн инструкцию по тому, как запустить сайт через OSPanel
4. откройте файл pages/index.php
5. если нужна база данных (логин, регистрация и др.) то см. ниже

Чтобы включить базу данных:

1. найдите файл config/db.example.php ;
2. переименуйте в db.php;
3. заполните его своими значениями;
4. импортируйте .sql базу данных в свой PhpMyAdmin.
